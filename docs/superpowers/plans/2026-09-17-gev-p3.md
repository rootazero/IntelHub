### T1 vessels：hub ais.rs collector
- `hub-core/Cargo.toml` + `tokio-tungstenite`（用户已批准的首个新 crate；feature 最小集 rustls）
- `monitor/sources/ais.rs`：env-gated `AISSTREAM_API_KEY`（HUB_ 前缀也收）；WS 连 stream.aisstream.io，订阅 PositionReport+ShipStaticData（全球，无 bbox 过滤）；mmsi→record 内存 map，STALE_SECS=600 修剪；每 15s 写 Redis `hub:globe:vessels`（TTL 300s，envelope 对齐 aircraft：count/ts/stale/coverage="aisstream"/records 字段 lat/lon/sog/knots→mps 换算/heading/name/mmsi/shipType）
- 重连退避（1s→60s cap，jitter），auth/429 文本分类（借 aisStreamAdapter.js 的 AUTH_TEXT/RATE_TEXT 语义）；健康格 `monitor:health:ais`
- 单测：mock 帧解析、mmsi 去重 fresher-wins、stale 修剪、无 key 不注册
- 验收：cargo test 绿；无 key 时 registry 无 ais 且日志一行说明

### T2 vessels：REST + console adapter
- `GET /api/v1/gev/vessels`：读 Redis 快照；无 key → 503 `{error:"aisstream not configured"}`
- `gev-adapters/vessels.ts`：按 T0 契约实现 vendor vessels source 接口（REST 轮询 15s）；替换 stubs.ts 中 vessels stub；LayerRail 注册表 vessels → 真实层
- 记录映射：AIS sog knots ×0.514444 → speedMps（Ruling 8 stale 派生沿用）
- 验收：vitest 映射单测；无 key 时层 enable 失败弹回 OFF（沿用 stub fail-closed 语义）

### T3 installations：迁移 + collector
- 迁移 `0020_military_installations.sql`（osm_type+osm_id 复合 unique, name, kind, lat, lon, tags jsonb, fetched_at）
- `monitor/sources/installations.rs`：24h 周期；Overpass 全球 `["military"]` 分 4 象限（抗超时），单象限失败退避重试 3 次后保旧数据；PG upsert；健康格
- Overpass 端点可配 `OVERPASS_URL`（默认 overpass-api.de）；请求间隔 ≥60s（礼貌）
- 验收：单测（QL 构造、响应解析、象限拆分）； collector 注册

### T4 installations：REST + adapter
- `GET /api/v1/gev/installations?south&west&north&east[&exact=1]`：bbox 校验照抄引擎规则（±90/±180、north>south、east>west、≤10°）；PG 查 bbox → `{elements, retrievedAt, status:"ok", saturated}` 契约形状
- `gev-adapters/installations.ts`：fetchImpl 路径改写 `/api/military-installations` → `/api/v1/gev/installations`；替换 stub
- 验收：bbox 非法 → 400；空 bbox → elements=[] 且 200

### T5 traffic：overpass 代理
- `POST /api/v1/gev/overpass`：Content-Type form；body 必须 `data=[out:json]` 前缀（白名单防滥用）；转发 OVERPASS_URL；Redis 缓存 300s（body hash）；超时 30s
- 验收：非法 body → 400；缓存命中二次响应 <50ms

### T6 traffic：tomtom status + flow 代理
- `GET /api/v1/gev/tomtom/status` → `{hasKey}`（secrets.env `TOMTOM_API_KEY`）
- `GET /api/v1/gev/tomtom/flow/{z}/{x}/{y}`：代理 `api.tomtom.com/traffic/services/4/flowSegments/...`（确切路径按 T0 契约）；Redis 缓存 60s；无 key 503
- 额度保护文档注释（200K/月免费档）
- 验收：status 反映 key 有无；无 key flow → 503
